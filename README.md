## 📌 Project Overview

This project analyzes Netflix titles across different release years to identify historical content trends using Python, Pandas, Plotly, and Streamlit.

**Internship:** Auspify Technologies  
**Domain:** Data Analysis Using Python

## 🎯 Objective

Analyze how Netflix titles are distributed across release years and identify historical content trends.

## 🛠️ Technologies Used

- Python
- Pandas
- Plotly
- Streamlit

## 🔄 Project Workflow

1. Organize titles by release year.
2. Calculate the number of titles for each year.
3. Identify years with high and low title counts.
4. Visualize trends using line and bar charts.
5. Interpret the observed patterns.

## ✨ Dashboard Features

- Total titles analyzed
- Earliest and latest release years
- Interactive release-year trend chart
- Top 10 release years
- Release-year range filter
- CSV download

## ▶️ How to Run

Install the dependencies:

```bash
pip install pandas streamlit plotly
```

Run the dashboard:

```bash
python -m streamlit run app.py
```
